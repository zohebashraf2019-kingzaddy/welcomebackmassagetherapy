# Welcome Back Massage Therapy

Website for Welcome Back Massage Therapy, Ellie Del Chiaro, LMT. 300 S. Wells Ave, Suite 8, Reno, NV 89502 (inside Stardust Reno).

Static site (HTML/CSS/JS, no build step). Deploy on Vercel: import the repo, framework preset **Other**, no build command, output directory = root.

- `index.html`: all page content
- `styles.css`: design (forest / sand / cream palette from the logo)
- `script.js`: scroll reveals, on-screen-only looping videos, breathing guide, open-now hours
- `assets/video/`: muted, looping studio clips (H.264, faststart) + poster frames
- `assets/img/`: logo (transparent PNGs), photos (WebP), favicon/OG image
